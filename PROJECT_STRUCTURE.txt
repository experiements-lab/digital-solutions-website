DEPLOYMENT OPTIONS
========================================================

Option 1: GitHub Pages (Free)
├── Create GitHub repository
├── Upload website files
├── Enable Pages in Settings
└── Site live at: username.github.io/repo-name

Option 2: Netlify (Free + Forms)
├── Connect GitHub repository
├── Auto-deploy on push
├── Forms work automatically
└── Site live at: site-name.netlify.app

├── Purchase domain (.co.za, .com, etc.)
├── Configure DNS settings
├── Link to GitHub/Netlify
└── Site live at: www.yourdomain.com
